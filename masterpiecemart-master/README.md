# Masterpiece Mart frontend

React 18 + Vite interface for the artwork catalogue, cart, wishlist and journal.

See the [project README](../README.md) for setup, API endpoints and the demo walkthrough.

```sh
npm ci
npm run dev
npm run build
```

Copy `.env.example` to `.env` to change `VITE_API_BASE_URL`. Default backend: `http://localhost:8080`.
